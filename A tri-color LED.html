A tri-color LED



A tri-color LED is an LED that contains three different colored light-emitting diodes (LEDs) in one package.
These three LEDs typically represent the primary colors of light: red, green, and blue (RGB).
When combined in various intensities
these LEDs can produce a wide range of colors
making tri-color LEDs highly versatile for applications like displays, indicators, and mood lighting.

How it works

Each color (red, green, and blue) in a tri-color LED is controlled independently.
By adjusting the brightness of each of the three LEDs
you can mix different levels of red, green, and blue light to create virtually any color in the visible spectrum.
This is the basic principle behind RGB color mixing.

There are two common types of tri-color LEDs:
1. Common Anode Tri-color LED:
All the cathodes (negative terminals) of the three LEDs are tied together
To a common pin, and each anode (positive terminal) is connected to a different pin.
When a voltage is applied to the anodes, it turns on the corresponding LED.

2. Common Cathode Tri-color LED:
All the anodes (positive terminals) are tied together
To a common pin, and each cathode (negative terminal) is connected to a different pin.
When the cathodes are grounded, the corresponding LED turns on.

Color Mixing

By adjusting the current passing through each of the red, green, and blue LEDs, you can mix the colors.
For example:
Red + Green = Yellow
Red + Blue = Magenta
Green + Blue = Cyan
Red + Green + Blue = White (when all are at full brightness)

Example Circuit for Controlling a Tri-Color LED

Let's say you have a common cathode tri-color LED, and you want to control it with an Arduino.
You would use PWM (Pulse Width Modulation) to adjust the brightness of each color.

int redPin = 9; // Pin connected to the red LED
int greenPin = 10; // Pin connected to the green LED
int bluePin = 11; // Pin connected to the blue LED

void setup() {
pinMode(redPin, OUTPUT);
pinMode(greenPin, OUTPUT);
pinMode(bluePin, OUTPUT);
}

void loop() {
// Set color to red
analogWrite(redPin, 255); // Full brightness (255)
analogWrite(greenPin, 0); // No green
analogWrite(bluePin, 0); // No blue
delay(1000); // Wait for 1 second

// Set color to green
analogWrite(redPin, 0); // No red
analogWrite(greenPin, 255); // Full green
analogWrite(bluePin, 0); // No blue
delay(1000); // Wait for 1 second

// Set color to blue
analogWrite(redPin, 0); // No red
analogWrite(greenPin, 0); // No green
analogWrite(bluePin, 255); // Full blue
delay(1000); // Wait for 1 second

// Set color to yellow (Red + Green)
analogWrite(redPin, 255); // Full red
analogWrite(greenPin, 255); // Full green
analogWrite(bluePin, 0); // No blue
delay(1000); // Wait for 1 second

// Set color to white (Red + Green + Blue)
analogWrite(redPin, 255); // Full red
analogWrite(greenPin, 255); // Full green
analogWrite(bluePin, 255); // Full blue
delay(1000); // Wait for 1 second
}

Applications of Tri-color LEDs

Displays:
Often used in LED displays where different colors are needed to display information.

Lighting:
Used in mood lighting and decorative lighting, allowing users to change colors as needed.

Indicators:
Tri-color LEDs are useful in devices where different colors signify different states
(e.g., green for normal, red for warning, blue for an alert).

The ability to mix red, green, and blue light makes tri-color LEDs ideal for creating dynamic lighting effects.
