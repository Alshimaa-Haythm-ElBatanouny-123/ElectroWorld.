Some Arduino projects

First Project (Smart Home Automation System)

Description
This project allows you to control your home appliances like lights, fans, and AC using a smartphone or sensors.

Components Needed:
* Arduino UNO
* Relay Module
* Bluetooth Module (HC-05) or Wi-Fi Module (ESP8266)
* Smartphone with an app (like Blynk)
* Power supply

How it works
The Arduino is connected to relays which control the appliances.
When you send a command from your smartphone (via Bluetooth or Wi-Fi), the Arduino receives it and turns the device ON or OFF accordingly.

Second Project (Weather Monitoring Station )

Description
A small station that measures temperature, humidity, and atmospheric pressure and displays it on an LCD or sends it to your phone.

Components Needed:
* Arduino UNO
* DHT11 or DHT22 Sensor (for temperature and humidity)
* BMP180 or BMP280 (for pressure)
* LCD Display or OLED
* Optional: Wi-Fi Module (to send data online)

How it works:
Sensors collect environmental data and send it to the Arduino.
The Arduino processes the data and displays it on the screen or sends it to a cloud service.

Third Project (Smart Irrigation System)

Description:
A system that waters plants automatically when the soil is dry.

Components Needed:
* Arduino UNO
* Soil Moisture Sensor
* Relay Module
* Water Pump or Solenoid Valve
* Water Source
* Power Supply

How it works:
The soil moisture sensor detects the dryness of the soil.
If the moisture is low, Arduino activates the relay, which turns on the water pump to irrigate the soil.

Fourth Projects (Obstacle Avoiding Robot)

Description:
A robot that can move around and avoid obstacles using sensors.

Components Needed:
* Arduino UNO
* Ultrasonic Sensor (HC-SR04)
* L298N Motor Driver
* Two DC Motors and Wheels
* Chassis and Battery Pack

How it works:
The ultrasonic sensor constantly checks the distance in front.
If it detects an obstacle, the Arduino decides to turn the robot left or right to avoid the obstacle.

Fiveth Project (RFID Door Lock System)

Description:
A secure door lock system that opens only with an authorized RFID card.

Components Needed:
* Arduino UNO
* RFID Module (RC522)
* Servo Motor (to open/close the lock)
* Buzzer (optional)
* RFID Tags/Cards

How it works:
When an RFID card is scanned, the Arduino checks if it’s an authorized card.
If yes, it activates the servo to unlock the door.
If not, it does nothing or sounds a buzzer.
