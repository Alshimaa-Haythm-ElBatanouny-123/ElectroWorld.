Arduino


Arduino is an open-source electronics platform based on easy-to-use hardware and software.
It’s designed for anyone making interactive projects — from hobbyists and students to engineers and professionals.

Arduino Hardware

Arduino boards are microcontroller-based development boards.
They are equipped with all the necessary components to connect sensors, actuators, and other components to control or interact with the environment.

Key Components of an Arduino Board

Microcontroller:
The brain of the board (e.g., ATmega328P on Arduino Uno).

Digital I/O Pins:
Used for input or output of digital signals.

Analog Input Pins:
Read analog signals from sensors (like temperature or light sensors).

Power Jack:
To supply power to the board.

USB Port:
Used for programming the board and powering it.

Reset Button:
Restarts the program running on the board.

Voltage Regulator:
Manages the voltage supplied to the board.

3. Arduino Software (IDE)

The Arduino IDE (Integrated Development Environment) is the software used to write code and upload it to the Arduino board.

The programming language is based on C/C++.
Common functions include:

* setup() – runs once when the board starts.
* loop() – runs continuously after setup().

Example:

void setup() {
pinMode(13, OUTPUT); // set pin 13 as output
}
void loop() {
digitalWrite(13, HIGH); // turn on LED
delay(1000); // wait 1 second
digitalWrite(13, LOW); // turn off LED
delay(1000); // wait 1 second
}
