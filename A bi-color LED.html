Bi-color LED



A bi-color LED is an LED that contains two different colored light-emitting diodes (LEDs) in one package.
These two LEDs are usually arranged in such a way that they can be individually controlled to produce two different colors.
The most common configuration involves a red LED and a green LED, but other color combinations, such as red and blue, are also used.

How it works

A bi-color LED typically has two leads (pins) or three leads:

1. Two-pin bi-color LED:
In this configuration, the LED has two pins, one for each color.
To change the color, you switch between the two pins to provide current to the corresponding LED.

2. Three-pin bi-color LED:
In this setup
there are three pins:
one common cathode (or anode) pin and two separate pins for the red and green LEDs.
The color changes depending on which LED (red or green) is activated.
The combination of the red and green LEDs can also create an additional color (like yellow).

How to control a bi-color LED

To control a bi-color LED, you use a microcontroller or circuit to provide voltage to the appropriate pins.
By turning on the red or green LED individually, you can display either color.
In a three-pin setup, both LEDs can be turned on at the same time
To create a mixed color (for example, red and green together produce yellow).

Example circuit for a bi-color LED

For a simple 3-pin bi-color LED, you can use an Arduino to control it:

int redPin = 9; // Pin connected to the red LED
int greenPin = 10; // Pin connected to the green LED
void setup() {
pinMode(redPin, OUTPUT);
pinMode(greenPin, OUTPUT);
}
void loop() {
// Turn on the red LED
digitalWrite(redPin, HIGH);
digitalWrite(greenPin, LOW);
delay(1000); // Wait for 1 second
// Turn on the green LED
digitalWrite(redPin, LOW);
digitalWrite(greenPin, HIGH);
delay(1000); // Wait for 1 second

// Turn on both LEDs (yellow)
digitalWrite(redPin, HIGH);
digitalWrite(greenPin, HIGH);
delay(1000); // Wait for 1 second

// Turn off both LEDs
digitalWrite(redPin, LOW);
digitalWrite(greenPin, LOW);
delay(1000); // Wait for 1 second
}

In this example, the LED will alternate between red, green, yellow (when both are on), and off.
